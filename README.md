# LeetMemo

A Chrome extension that helps you actually remember LeetCode solutions using spaced repetition.

You solve a problem, LeetMemo schedules it for review. When it's due, you re-solve it and mark Pass or Fail — pass pushes the next review further out (1 → 3 → 7 → 14 → 30 → 60 → 120 days), fail resets it back to day 1.

## What it does

- Shows your LeetCode profile, solved counts, and rank
- Displays a GitHub-style submission heatmap for the year
- Lists your recent accepted submissions with per-problem notes
- Automatically queues every solved problem for spaced-repetition review
- Shows which problems are due today with one-click Pass/Fail buttons
- Opens problems directly on LeetCode when you click the title
